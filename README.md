# CLAUDE МОНТАЖ | ТЕЛЕФОН

Видеоны телефоннан, Claude арқылы монтаждауға арналған дайын шаблон.
Бағдарлама орнатудың қажеті жоқ, бәрі чат арқылы жасалады.

## Қалай жұмыс істейді (телефоннан)

1. Осы шаблонды ашасыз, сізге дайын орта қосылады.
2. Видеоңызды **чатқа жібересіз**.
3. Claude оны монтаждайды (грейд, титр, хук, музыка).
4. Дайын видеоны Claude **чатқа файл етіп қайтарады**, сіз телефонға сақтайсыз.

Папкаларды қазбалаудың қажеті жоқ. Бәрі чат арқылы: видео жібердіңіз → дайынын алдыңыз.

## Алғашқы рет

Бір рет чатқа жазыңыз:

```
bash setup.sh
```

Бұл ffmpeg-ті орнатып, ортаны дайындайды.

## Монтаж жасау

1. Видеоны чатқа жіберіңіз.
2. Жазыңыз: «осы видеоны монтажда».
3. Керек болса, стиль не музыка туралы айтыңыз.
4. Claude алдымен жоспар мен стоп-кадр көрсетеді, мақұлдасаңыз, дайын видеоны жібереді.

## Файлдар

- `brand.md`, түстер мен шрифттер (өзгертуге болады).
- `assets/fonts/`, қазақ әріптері бар шрифттер.
- `assets/music/`, музыка.
- `videos/`, әр видео өз папкасында.
- `.claude/skills/montage/`, монтаж процесі.
