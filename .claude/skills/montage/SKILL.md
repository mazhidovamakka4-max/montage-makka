# Навык монтажа

Пошаговый процесс сборки ролика. Оформление всегда из `brand.md`.

## 1. Подготовка
- Проверь, что `setup.sh` выполнен (есть ffmpeg): `ffmpeg -version`.
- Прочитай `brand.md` (цвета, шрифты).
- Найди исходное видео в `videos/<проект>/source.mp4`.

## 2. Разбор видео
- Узнай длительность и разрешение: `ffprobe`.
- Если нужны титры, распознай речь по словам (whisper, язык казахский `-l kk` или русский `-l ru`).
- Выверь текст, сомнительные казахские слова покажи пользователю.

## 3. План
- Предложи короткий план сцен таблицей: время, текст на экране, переход, звук.
- Дождись подтверждения пользователя.

## 4. Сборка
- Картинка: мягкий тёплый грейд, лёгкий медленный зум. Без тряски и вспышек, если не просили.
- Титры: по одному слову, шрифт с казахскими буквами из `brand.md`, появляется когда звучит.
- Хук в первые 1.5 секунды: крупно, коротко, контрастно.
- Акценты и графика, в красном цвете бренда.
- Звук: голос выровнять по громкости; музыка только по просьбе и тише голоса.

## 5. Проверка
- Сделай стоп-кадры ключевых моментов, покажи пользователю.
- Проверь правила качества из `CLAUDE.md` (поля, 1–4 слова, читаемость с телефона).
- Рендерь финальный MP4 только после одобрения. Клади его в папку проекта.

## Помощники
- `scripts/` — сюда можно складывать свои вспомогательные скрипты (нарезка, сведение звука).
- Начни с простого: ffmpeg для грейда, зума и наложения титров. Усложняй по мере надобности.
