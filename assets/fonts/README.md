# Шрифты

Шрифты с казахскими буквами (.ttf / .otf). Claude подключает их через @font-face.

В шаблоне уже лежит:
- Montserrat.ttf — бесплатный (SIL OFL), для текста и заголовков (вес 800/900).

Если хочешь фирменные заголовки Druk Wide:
- Druk Wide — платный шрифт, его нельзя класть в публичный репозиторий.
- Добавь свой лицензионный файл сюда локально, и укажи его в brand.md.

Важно: в Unbounded и JetBrains Mono казахских букв нет, для казахского их не клади.
