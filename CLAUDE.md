# Монтаж через Claude

Это рабочий шаблон для монтажа коротких видео (Reels, Shorts, сторис) с помощью Claude.
Claude читает этот файл при каждом запуске. Здесь правила, по которым мы собираем ролики.

## С чего начать (первый запуск)

1. Запусти настройку: `bash setup.sh` (ставит ffmpeg и проверяет окружение).
2. Прочитай `brand.md`, оттуда берутся цвета и шрифты.
3. Положи шрифты в `assets/fonts/`, музыку в `assets/music/`.
4. Своё видео клади в `videos/<имя-проекта>/source.mp4`.

## Папки

- `brand.md` — цвета, шрифты, характер бренда. Всегда бери оформление отсюда.
- `assets/fonts/` — шрифты с казахскими буквами, подключаются через @font-face.
- `assets/music/` — музыка (только с лицензией для свободного использования).
- `videos/` — каждый ролик в своей подпапке.
- `.claude/skills/montage/` — навык монтажа, пошаговый процесс для Claude.

## Порядок работы над роликом

1. Спроси у пользователя до 3 вопросов, если чего-то не хватает (формат, о чём ролик, есть ли музыка). Не выдумывай факты.
2. Покажи короткий план сцен: время, текст на экране, переход, звук. Дождись «ок».
3. Собери ролик по навыку `.claude/skills/montage/SKILL.md`.
4. Сделай стоп-кадры ключевых моментов и покажи их. Рендер только после одобрения.
5. Готовый MP4 положи в папку ролика.

## Стиль по умолчанию

- Картинка: тёплый, мягкий, «киношный» вид. Лёгкий медленный наезд камеры. Без тряски, вспышек и глитча, если не попросили.
- Звук: родной голос, громкость выровнена. Музыка только если пользователь попросил, и всегда тише голоса.
- Титры: по одному слову, крупно и чисто, шрифт с казахскими буквами (см. `brand.md`). Слово появляется ровно когда звучит.
- Первые 1.5 секунды, сильный хук: крупно, коротко, контрастно.
- Графика и акценты, в цветах бренда (красный акцент).

## Форматы

- Reels, Shorts, сторис: 1080×1920, 30 fps.
- Пост в ленту: 1080×1350.
- YouTube, экран: 1920×1080.
- Если формат не указан, спроси.

## Правила качества (проверяй перед показом)

- На экране одновременно не больше 1–4 слов.
- Нет статичных кусков дольше 2 секунд.
- Максимум 2 шрифта и 1 акцентный цвет.
- Текст не ближе 8% к краю кадра.
- Шрифты с казахскими буквами подключены через @font-face.
- Ролик читается с телефона в уменьшенном виде.
